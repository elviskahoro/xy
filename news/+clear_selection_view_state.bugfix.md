Fixed `FigureWidget.clear_selection()` (and the `reflex_xy.clear_selection` room-wide mirror) leaving `Figure.view_state()['selection']` stale at the last range when the `select` interaction flag is off (`interaction.select=False`, or any `coords="polar"` chart, which forces select off). The kernel-side durable cache now records the clear eagerly, mirroring the existing `rows=` path in `select()`, so client and kernel stay consistent regardless of whether the client's flag-gated `select_clear` echo reaches the kernel.
